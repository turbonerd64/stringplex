# Saved Guitar Profiles Directory

This directory stores backup `.json` acoustic profiles for StringPlex.

## How to permanently bundle your profile:
1. Click **`💾 Backup (96/96)`** in StringPlex to download your profile JSON file.
2. Copy the downloaded file into this folder (`stringplex/profiles/`).
3. You can also name it `defaultProfile.json` to have it load automatically whenever localStorage is empty.
